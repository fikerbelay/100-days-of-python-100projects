# Silent Auction

A simple **Python Silent Auction** program that allows multiple people to place bids and determines the highest bidder at the end.

## How It Works

1. The user enters their name.
2. The user enters their bid amount.
3. The program asks if there are more bidders.
4. If there are more bidders, the process continues.
5. When bidding ends, the program finds and displays the highest bidder.

## Example

```text
What is your name?: Yuta
What is your bid?: $100
Are there any other bidders? Type 'yes' or 'no'.
yes

What is your name?: Alex
What is your bid?: $150
Are there any other bidders? Type 'yes' or 'no'.
no

The winner is Alex with a bid of $150
```

## Technologies Used

* Python

## How to Run

Make sure Python is installed, then run:

```bash
python main.py
```

## Features

* Accepts multiple bidders
* Stores bids using a Python dictionary
* Automatically finds the highest bid
* Displays the winner and winning bid

This project was created to practice **Python dictionaries, loops, functions, conditionals, and user input**.
