Etch-A-Sketch 🎨

A digital Etch-A-Sketch built with Python's `turtle` module. Use your keyboard to draw on screen just like the classic toy!

This is **Day 19** of my [#100DaysOfCode](https://www.udemy.com/course/100-days-of-code/) journey the **Etch-A-Sketch** project from Dr. Angela Yu's *100 Days of Code: The Complete Python Pro Bootcamp*.

---

## 🎮 How It Works

Use these keys to control the turtle:

| Key | Action |
|-----|--------|
| `W` | Move forward |
| `S` | Move backward |
| `A` | Turn left |
| `D` | Turn right |

Draw whatever you like — there's no "clear" button yet, so make it count! 😄

---

## 🧠 Concepts Practiced

- **Event listeners** — `screen.onkey()` and `screen.listen()`.
- **Higher-order functions** — passing functions as arguments.
- **The `turtle` module** — `Turtle`, `Screen`, and movement methods.
- **Keyboard bindings** — mapping keys to functions.

## 🛠️ Requirements

- Python 3.x
- The `turtle` module (pre-installed with standard Python)

## 🚀 How to Run

```bash

```
