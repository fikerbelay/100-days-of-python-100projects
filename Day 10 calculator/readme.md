# Calculator

A simple **Python calculator** that performs basic mathematical operations using functions and a dictionary.

## How It Works

1. The user enters the first number.
2. The user chooses an operator: `+`, `-`, `*`, or `/`.
3. The user enters the next number.
4. The program calculates and displays the result.
5. The user can continue calculating with the previous result or start a new calculation.

## Example

```text
Enter first number: 10
pick an operator "+", "-", "*" or "/": *
What is the next number?: 5

10.0 * 5.0 = 50.0

Type 'y' to continue calculating with 3.0, or type 'n' to start a new calculation:
```

## Supported Operations

| Operator | Operation      |
| -------- | -------------- |
| `+`      | Addition       |
| `-`      | Subtraction    |
| `*`      | Multiplication |
| `/`      | Division       |
