# 🔼 Higher Lower — Who Has More Followers?

A CLI game built in Python where you guess which of two celebrities, brands, or public figures has more followers. Built as part of my **#100Projects** challenge.

## 📖 About

Two profiles are shown **Compare A** and **Compare B**. Your job? Guess which one has more followers on social media. Get it right and your score goes up. Get it wrong and the game ends. How long can you last?

## 🎮 How to Play

1. Run the program. A random profile is shown as **Compare A**.
2. A second profile appears as **Compare B**.
3. Type `A` or `B` to guess who has more followers.
4. If you're right, your score increases and **B becomes the new A**.
5. If you're wrong, the game ends and your final score is displayed.
